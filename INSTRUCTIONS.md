# How to Set Up Your GitHub Profile

1.  **Create a New Repository**:
    *   Go to GitHub and create a new repository.
    *   **Important**: Name the repository exactly the same as your GitHub username (e.g., if your username is `AI-Researcher-2027`, the repo name must be `AI-Researcher-2027`).
    *   Check the box **"Add a README file"**.

2.  **Update the Content**:
    *   Copy the content from the `README.md` file I generated in this folder.
    *   Open your new repository on GitHub, click the `README.md` file, and click the pencil icon to edit.
    *   Paste the content.

3.  **Fill in the Blanks**:
    *   Replace `[Your Name]` with your actual name.
    *   Replace `[your-username]` with your GitHub username (CRITICAL for the stats widgets to work).
    *   Replace `[your-linkedin]` and `[your-email]` with your details.
    *   Update the "Project Name" placeholders with your actual projects if you have them.

4.  **Save**:
    *   Commit the changes. Your profile page will now show this bio!

## Tips for PhD & Global Talent Visa

*   **Pinned Repos**: Pin your most complex/impressive AI projects.
*   **Green Squares**: Commit often. The visual activity graph matters for the "Evidence of active contribution" part of the visa.
*   **Documentation**: Ensure your individual project READMEs are just as good as this profile one.
